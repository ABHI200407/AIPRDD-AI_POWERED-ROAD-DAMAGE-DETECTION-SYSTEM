1. Problem Statement

  • Blind to Hazards: Standard GPS apps (Google Maps, Waze) optimize for speed or distance, ignoring the physical condition of the road.
  • The Pothole Epidemic: Poor road infrastructure causes thousands of fatal accidents and millions in vehicle damage annually.
  • Vulnerability Ignored: A pothole that is a minor bump for a truck can be a lethal hazard for a two-wheeler, yet current routing treats all vehicles the same.
  • Reactive vs Proactive: Municipalities rely on slow, manual inspection processes rather than real-time, data-driven repair routing.

"The Fastest Route is not always the Safest Route."

2. Objectives

1. Detect Damage

Utilize YOLOv8 to classify and score road hazards (D00-D40) from citizen reports.

2. Safety-Aware Routing

Build an A* pathfinding engine that penalizes damaged road segments.

Implement dynamic penalty factors based on vehicle vulnerability (Bike vs Truck).

4. Real-Time Sync

Use WebSockets to broadcast new hazards to all active navigation clients instantly.

5. Municipal Command Center

Provide authorities with SLAs, priority queues, and optimal repair crew routing.

6. A* Routing Engine

How it works:

  1. Fetch Map: Query Overpass OSM API for local road network geometry.
  2. Build Graph: Convert roads into a NetworkX graph. Compute travel time based on highway speed limits.
  3. Spatial Index: Build a KD-Tree to snap GPS points to the nearest graph node in O(log N) time.
  4. Penalize: Add time penalties to edges that contain reported hazards.
  5. Solve: Run A* heuristic search (Haversine distance) to find the optimal path.
  6. Navigate: Interpolate nodes to generate turn-by-turn instructions.

7. Vehicle-Specific Routing

🏍️ BIKE

  • Factor: 3.0x
  • Highly vulnerable.
  • System diverts bike routes even for minor D10/D20 cracks.
  • Max Safe Severity: 2

🚗 CAR / SUV

  • Factor: 1.0x
  • Standard vulnerability.
  • Tolerates minor cracks, but strictly avoids D40 potholes.
  • Max Safe Severity: 3

🚛 TRUCK / BUS

  • Factor: 0.4x
  • Heavy suspension.
  • Prioritizes direct routes; ignores minor surface damage.
  • Max Safe Severity: 5

8. Dynamic Route Modes

⚡ FASTEST

Penalty Mod: 0.1
Optimizes for speed. Accepts minor suspension wear to get to the destination quickly. Ideal for emergencies.

🛡️ SAFEST / SMOOTHEST

Penalty Mod: 1.0
Zero tolerance for damage. Will take longer detours to ensure a pristine road surface.

🌙 SAFE_AT_NIGHT

Penalty Mod: 0.5
Avoids severe potholes, but prioritizes staying on main, well-lit roads rather than detouring through dark residential streets.

⚖️ BALANCED

Penalty Mod: 0.5
The default setting. A calculated compromise between route time and vehicle safety.

  • Road Quality Score (1-5): Overall segment health.
  • Suspension Index (0-100%): Likelihood of shock absorber damage.
  • Estimated Wear Cost: Real-world financial cost (INR) of taking a damaged route.
  • Geometry: Array of Lat/Lng points with Turn-by-Turn instructions.

  • Analytics: City-wide repair status tracking.

11. Advanced System Intelligence

  • Fraud Detection via Perceptual Hashing: Citizens attempting to upload the same pothole image twice (or a downloaded image) are blocked instantly via image hashing algorithms.
  • Road Health Heatmaps: The backend clusters GPS data to highlight rapidly deteriorating neighborhoods, allowing proactive rather than reactive budgeting.
  • Live WebSocket Broadcasts: If a citizen reports a pothole, the server instantly pushes the coordinate to all users currently navigating, dynamically recalculating their route mid-trip if necessary.
