🚀 Abstract

Traditional navigation systems optimize routes based solely on distance or traffic congestion, completely ignoring the physical condition of the road surface. This poses severe safety risks, particularly for vulnerable vehicles like two-wheelers. SafePath AI bridges this gap by integrating real-time road hazard data (detected via YOLOv8 and citizen reports) directly into an advanced pathfinding engine. Utilizing a custom A* algorithm operating on a NetworkX graph populated with OpenStreetMap data, the system calculates safety-aware routes. It applies dynamic penalty weights to hazardous road segments based on vehicle-specific vulnerability profiles, successfully diverting high-risk vehicles away from severe damage while minimizing travel time disruptions.

🧠 Routing Logic

The core innovation is the dynamic edge-weight penalty applied during the A* search. When a hazard is detected near an OSM road segment, a time-equivalent penalty is added to that edge, discouraging the pathfinder from using it.

Edge_Weight += (Severity²) × 50s × Vehicle_Factor

Impact: A "D40 Pothole" (Severity 4) creates an 800-second penalty for a Bike (3.0x), but only a 106-second penalty for a Truck (0.4x), ensuring safe divergence for vulnerable commuters.
