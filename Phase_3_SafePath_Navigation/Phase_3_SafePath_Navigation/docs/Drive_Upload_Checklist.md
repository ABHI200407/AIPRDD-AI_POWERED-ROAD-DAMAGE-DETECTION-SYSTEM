## 🖨️ How to Convert HTML Docs to PDF

The Project Report and Poster are generated as high-quality HTML files. To save them as PDFs for submission:

1. Open the `.html` file in **Google Chrome** or **Microsoft Edge**.
2. Press `Ctrl + P` (or Cmd + P on Mac) to open the Print dialogue.
3. Set **Destination** to `Save as PDF`.
4. Open the **More settings** dropdown.
5. **IMPORTANT:** Check the box for **Background graphics** (this ensures all colors, gradients, and styling are saved properly).
6. Click **Save**.
