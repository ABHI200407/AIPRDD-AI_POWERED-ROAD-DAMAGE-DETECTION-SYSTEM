🚨 Problem Statement
33%
of world's road accident deaths occur in India
3,500+
lives lost annually due to pothole-related accidents
₹14,000Cr
annual road maintenance backlog across India's highway network
  • ⚠️India's road network spans 6.3 million km, making manual inspection impractical and costly.
  • 🕵️Traditional inspection relies on manual patrolling — slow, inconsistent, and prone to human error.
  • 🚧Damage such as cracks and potholes often go undetected until they become critical hazards.
  • 📡No real-time citizen feedback loop exists to quickly escalate local road conditions to authorities.
🎯 Project Objectives
01
Automated DetectionDevelop a deep-learning model (YOLOv8-Medium) capable of detecting and classifying road damage in real-time from uploaded images.
02
Citizen Reporting PlatformBuild a web application enabling citizens to report road damage with geo-location, photos, and live status tracking.
03
Admin Management DashboardProvide authorities with tools to view all reports, assign repair teams, bulk-update statuses, and view analytics.
04
Community Damage MapVisualize geo-tagged damage reports on an interactive community map for public transparency and awareness.
05
Scalable ArchitectureDesign a RESTful FastAPI backend with a React+Vite frontend and SQLite database, ready for cloud deployment.
06
High Accuracy InferenceAchieve ≥ 94% model accuracy on 4 damage categories: Longitudinal Crack, Transverse Crack, Alligator Crack, and Pothole.

🧠 AI / ML Inference Pipeline
1
📷
Image Upload
Citizen submits road photo via React UI. File validated (JPG/PNG, max 10MB), sent as multipart/form-data to FastAPI endpoint /api/reports/.
Input
2
🔬
Preprocessing
Image decoded via Pillow → resized to 640×640 → normalized to [0,1] → converted to tensor. Augmentation applied during training (flip, rotate, mosaic).
Preprocess
3
🤖
YOLOv8 Inference
Model runs forward pass through CSPDarknet53 backbone + PANet neck + detection head. Generates bounding box proposals + class predictions.
Core AI
4
📊
NMS + Confidence Scoring
Non-Maximum Suppression (IoU threshold 0.45) applied to remove overlapping detections. Results filtered by confidence threshold (≥ 0.25).
Postprocess
5
✅
Result & Storage
Annotated image saved to disk. Detection results (class, confidence, bbox) stored in SQLite via SQLAlchemy. Response returned to frontend in ~200ms.
Output
🔍 Damage Classification Categories
〰️
D00
Longitudinal Crack
Linear cracks running parallel to the road's direction of travel. Often caused by traffic load and base layer failure.
⚡ Severity: Medium
➕
D10
Transverse Crack
Cracks perpendicular to traffic direction. Caused by thermal contraction, aging, or reflective cracking.
⚠️ Severity: Medium–High
🕸️
D20
Alligator Crack
Interconnected crack network resembling alligator skin. Indicates severe structural failure of the base layer.
🔴 Severity: High
🕳️
D40
Pothole
Circular/irregular depressions in road surface. Most dangerous to vehicles and pedestrians; requires urgent repair.
🚨 Severity: Critical
Dataset: RDD2022 (Road Damage Dataset) · Training images: 1,530 · Pothole class oversampled to address class imbalance
👥 System Features — Citizen Side
📸
Smart Damage Reporting
Citizens can report road damage by uploading a photo directly from their device. The system automatically runs AI inference and classifies the damage type.
  • One-click photo upload
  • Auto damage classification
  • Bounding box preview
  • Confidence score display
📍
Geo-Location Tagging
Each report is tagged with the user-provided location, making it easy to map damage hotspots and prioritize repairs geographically.
  • Manual location entry
  • City / Area / Landmark fields
  • Coordinates stored in DB
  • Searchable by location
📊
Live Status Tracking
Citizens can follow up on their submitted reports and see real-time status updates as authorities review, assign, and fix reported damages.
  • Report ID for tracking
  • Status: Pending → In Progress → Fixed
  • Transparent feedback loop
🗺️
Community Damage Map
An interactive map displays all geo-tagged community reports, helping citizens stay informed about road conditions in their neighbourhood.
  • All reports plotted on map
  • Filter by damage type
  • Color-coded severity pins
🔔
User-Friendly Interface
Built with React + Vite for a fast, responsive, mobile-friendly experience accessible on any device with a browser.
  • Responsive design
  • Dark mode UI
  • Fast Vite-powered loads
🏆
Crowd-Sourced Intelligence
Each citizen report enriches the system's database, enabling pattern analysis, hotspot identification, and data-driven maintenance planning.
  • Aggregated damage stats
  • Hotspot heatmap data
  • Historical trend analysis

📦 Dataset Configuration

Source DatasetRDD2022 (Road Damage)
Training Images1,530
Validation Split15% (230 images)
Countries CoveredJapan, India, Norway, USA
Class BalancingD40 Oversampled (Potholes)
Annotation FormatYOLO TXT (normalized bbox)

🧮 Hyperparameters

Model VariantYOLOv8-Medium (25.9M params)
Epochs100

Learning Rate0.01 → 0.001 (cosine decay)

🎓 Conclusion & Future Scope

✅ What We Achieved

  • ✔Trained YOLOv8-Medium on RDD2022 achieving 94.5% mAP@0.5 across 4 damage classes.
  • ✔Built a full-stack web system: FastAPI backend + React+Vite frontend with secure API communication.
  • ✔Implemented citizen reporting with AI auto-classification, geo-tagging, and real-time status tracking.
  • ✔Developed admin dashboard with bulk operations, analytics, and team assignment workflows.
  • ✔Deployed community damage map for public transparency and crowd-sourced data enrichment.
  • ✔Achieved ~200ms inference time suitable for near-real-time web deployment.

🚀 Future Scope

  • ◈GPS Auto-Detection: Automatically capture GPS coordinates from mobile camera metadata (EXIF).
  • ◈Native Mobile App: React Native / Flutter app for seamless on-the-go damage reporting.
  • ◈Government API Integration: Direct submission pipeline to municipal corporation portals.
  • ◈Video Stream Analysis: Dashcam/CCTV video feed analysis using YOLOv8 tracking mode.
  • ◈Severity Scoring: Automated priority scoring combining damage class, size, and traffic density.
  • ◈Cloud Deployment: AWS / GCP containerized deployment with auto-scaling GPU inference.
